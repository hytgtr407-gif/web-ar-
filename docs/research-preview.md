# 用户体验研究预览

入口：`study.html`；内容：`assets/data/study-scene.json`；内容版本：`bgj-study-v1`。

研究预览用于人工专家审核之前的操作、交互体验和感知学习支持评价。页面持续标注文化说明待专家审核；三段人物说明按附带公开来源概括，不冒称已获池晗老师确认。当前 AR 层是半透明平面，人物文字在信息面板展示，不代表完整多媒体或三维人物阅读系统。

正式 `index.html` 仍使用 `scene.json` 和严格三字段门控，未通过审核不能正常发布。研究预览不伪造 audited：两份数据的三位人物均为 audited=false。

独立研究入口仅在唯一失败原因为 audited=false、身份和资源声明匹配、预览许可严格为 true、内容版本精确匹配且有 HTTPS 资料来源时显示待审草稿。错误身份、缺失数据、资源或版本条件不满足，仍隐藏内容。来源链接只记录起草依据，不提供自动事实核验。

日志保留 `semantic_gate_block`，并另记 `research_preview_display`，不把预览展示记为 `semantic_gate_pass`。CSV 增加 `study_mode` 和 `content_version`；不能把研究例外展示当作正式门控放行的功能证据。移开卡片时研究内容与正式内容一样隐藏。

研究流程：先固定预览版本及材料 → 2–3 人预测试 → 约 30 人原型体验评价 → 按实际数据写论文主体 → 池晗老师审核人物/剧情表达及论文 → 修订、验证与完成终稿。前后自评理解和客观知识增长不是本次主实验。未同意参加者退出。

向参与者说明：“这是研究预览，人物说明依据公开资料整理，尚待专家审核。请评价操作和展示体验，不将页面出现内容理解为专家确认。”SUS 在详细机制解释前填写。题目测系统操作、衔接和用户感受；不宣称证明文化真实性或学习增益。

将问卷编号与每份日志文件在现场记录表中对应保存；导出日志的随机 session ID 不是问卷编号。分母按实际完成和各题有效回答分别记录。

修改记录：保留实验使用的文字、图片、内容版本及 commit。若老师只修正错字等不影响语义的内容，可保留该版本的可用性结果并说明修订；涉及人物关系、剧情含义、信息量或操作流程变化时，逐项判断相关理解/体验结论是否仍适用，必要时重测。不能笼统写内容修改不会影响实验。
